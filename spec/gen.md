# 合成プレート生成の仕様（C++ と Python が従う唯一の定義）

生成器は 2 つある（`pure/gen.hpp` + `jlpr gen` / `tools/gen.py`）。同じ seed で **同じラベルと同じ幾何**を
出すことがパリティの条件で、そのためには「どの順に乱数を引くか」まで決めておく必要がある。この文書が
その順序表。ラスタライズ（文字の描画）だけは stb_truetype と PIL/FreeType で必ず違うので、**画像の一致は
求めない**（統計と目視で同等を確認する）。

乱数は `pure/rng.hpp` / `tools/rng.py` の splitmix64 だけを使う。1 サンプル目の state は `seed + index`
ではなく **`Rng(seed)` を 1 個作って連続して引く**（サンプル間で状態が継続する）。`--start` で途中から
再開したい場合は、`index` 個分の draw を捨てるのではなく `Rng(seed ^ (index * 0x9E3779B97F4A7C15))` を
使う（並列生成できるように）。

## 1 サンプルあたりの draw 順序

| # | 引くもの | 引き方 | 備考 |
|---|---|---|---|
| 1 | `kind` | `below(100)` を重みに割り当て | 0-49 自家用普通 / 50-64 軽自家用 / 65-74 事業用普通 / 75-79 軽事業用 / 80-89 大型 / 90-99 図柄入り |
| 2 | `region` | `below(138)` | `spec/labels.txt` の region head の index |
| 3 | `cls_len` | `below(100)` | 0-79 → 3桁 / 80-94 → 2桁 / 95-99 → 1桁 |
| 4 | `cls_first` | `below(9) + 1` | 分類番号の先頭は 1..9（用途区分） |
| 5 | `cls_rest[i]` | 各桁 `below(20)` | 3桁のときのみ 2 回、2桁のときは 1 回、1桁なら 0 回。`class_num_02/03` のトークン表（`0-9ACFHKLMPXY`）の index |
| 6 | `hira` | `below(kind の許容集合サイズ)` | 許容集合は下の表。index は集合内の順番で、そこから `spec/labels.txt` の hiragana index に写す |
| 7 | `serial_len` | `below(100)` | 0-84 → 4桁 / 85-94 → 3桁 / 95-98 → 2桁 / 99 → 1桁 |
| 8 | `serial[i]` | 各桁 `below(10)` | 左詰めせず**右詰め**（空き桁は先頭側、表示は `・`）。ただし全桁 0 は避ける（0 が出たら 1 を足す、最下位のみ） |
| 9 | `yaw` | `range(-35, 35)` 度 | プレート面の水平回転 |
| 10 | `pitch` | `range(-20, 20)` 度 | 上下 |
| 11 | `roll` | `range(-8, 8)` 度 | 画面内回転 |
| 12 | `plate_px` | `range(24, 200)` | 出力 crop に対するプレート幅の見え（低解像度を必ず含める） |
| 13 | `margin` | `range(0.02, 0.18)` | crop がプレート外形の何割外まで含むか |
| 14 | `off_x` | `range(-0.05, 0.05)` | crop 中心のずれ（プレート幅比） |
| 15 | `off_y` | `range(-0.05, 0.05)` | 同（高さ比） |
| 16 | `brightness` | `range(0.45, 1.35)` | 乗算 |
| 17 | `contrast` | `range(0.7, 1.3)` | |
| 18 | `warm` | `range(-0.12, 0.12)` | R と B を逆方向に振る（色温度） |
| 19 | `blur` | `range(0, 1.6)` px | ガウシアン σ |
| 20 | `motion` | `range(0, 3.0)` px | 水平モーションブラー長 |
| 21 | `noise` | `range(0, 12)` | 加算ガウスノイズ σ（0-255 スケール） |
| 22 | `jpeg_q` | `below(60) + 40` | 40..99 |
| 23 | `dirt` | `range(0, 0.35)` | 汚れ・かすれの強さ |
| 24 | `bolt` | `below(100)` | 0-79 ボルト 2 本 / 80-94 なし / 95-99 4 本 |
| 25 | `seal` | `below(100)` | 0-69 封印あり（左上）/ 70-99 なし |
| 26 | `frame` | `below(100)` | 0-84 なし / 85-99 フレーム縁あり |
| 27 | `bg_hue` | `range(0, 1)` | 背景（車体）色 |
| 28 | `bg_dark` | `range(0.15, 0.85)` | 背景の明るさ |

`legible` ラベルは乱数ではなく**上の値から決める**（両実装で同じ式）:

    illegible = (plate_px < 40) or (blur > 1.2) or (motion > 2.2) or (noise > 9) or (dirt > 0.28)
    legible   = illegible ? "no" : "yes"

## ひらがなの許容集合（kind ごと）

実在しない `お・し・へ・ん` は元から入れない。`spec/labels.txt` の hiragana head 53 トークンのうち:

| kind | 使うトークン |
|---|---|
| 自家用（普通・軽・大型・図柄入り） | `あいうえかきくけこさすせそたちつてとなにぬねのはひふほまみむめもやゆよらりるれろ`（44） |
| 事業用（普通・軽） | `あいうえかきくけこを`（10） |

レンタカーの `わ・れ`、駐留軍のアルファベットは初版の生成対象外（head には残す）。

## レイアウト（実寸 mm ベース、描画時に px へスケール）

| | 中型 / 軽 | 大型 |
|---|---|---|
| 外形 | 330 × 165 | 440 × 220 |
| 角丸 | 半径 10 | 半径 13 |
| 地名 文字高 | 40（上段左） | 53 |
| 分類番号 文字高 | 40（上段右） | 53 |
| ひらがな 文字高 | 60（下段左） | 80 |
| 一連番号 文字高 | 90（下段右） | 120 |

上段のベースラインは上端から 55mm、下段は上端から 145mm（大型は比例）。一連番号は 2 桁ずつに分け、
間にハイフン（`-`）を描く。空き桁は `・` を描く。

## 色（kind → 地色 / 文字色）

| kind | 地色 | 文字色 |
|---|---|---|
| 自家用普通・大型 | 白 (250,250,248) | 緑 (16,90,60) |
| 事業用普通 | 緑 (16,90,60) | 白 (250,250,248) |
| 軽自家用 | 黄 (240,205,20) | 黒 (25,25,25) |
| 軽事業用 | 黒 (25,25,25) | 黄 (240,205,20) |
| 図柄入り | 白地に模倣柄（実物の図柄は著作権があるので、抽象的なグラデーション＋図形で近似） | 緑 |

## 出力

- 認識用: `<out>/plate%06d.png`（正方形 crop）と `labels.txt`
  （`<file> <11 個の head index>`）＋ `corners.txt`（`<file> x1 y1 x2 y2 x3 y3 x4 y4`、左上から時計回り、
  crop 内 px 座標）＋ `meta.txt`（幾何と劣化パラメータ全部。パリティ比較の対象）
- 検出用（M7）: 車写真への貼り込みは別コマンド。ここでは扱わない。

`meta.txt` は両言語でバイト一致することを `tools/parity/gen.py` が確認する。書式は
`<file> kind=<tok> region=<idx> cls=<str> hira=<idx> serial=<str> yaw=%.4f ...`（数値は全て `%.4f`）。
